# Moroccan Positioning & CRO Copy System

Chifaglow is a **premium DTC USB brand** for Morocco. The offer is not “cheap flash drives”. The offer is **ready-to-play spiritual, educational, and entertainment libraries** that arrive at the door, paid in cash.

Primary language: **Moroccan Darija mixed with clear MSA**. Ads traffic (TikTok / Instagram / Facebook) reads Darija faster than formal Arabic. Checkout labels stay short and formal so errors drop.

---

## 1. Market constraints that drive the funnel

| Reality in Morocco | Store decision |
|---|---|
| Card checkout kills conversion | COD only. Never show card logos. |
| Trust is low for unknown brands | Authority badges, reviews with city names, COD + free shipping as default |
| Mobile + slow 4G from ads | One-thumb path. Sticky CTA. Popup checkout (no multi-page). Deferred pixels. |
| AOV is pressure | Tiered 1 / 2 / 3 pricing. Cross-sell at full 199. Discount **only** on the 12s upsell (99 DH). |
| Delivery anxiety | “24–48 ساعة لجميع المدن” + city dropdown (proves we actually ship there) |
| Phone is the identity | Strict 05 / 06 / 07 / +212 validation. Ops call this number. |

Currency on every price: **DH** or **درهم** (never `$`).

## 3. Darija / Arabic copy rules

1. **Headlines** — Darija rhythm, 8–14 words. Speak to the buyer’s home, not the SKU.
2. **Body** — mixed Darija + MSA. Avoid slang that feels cheap (`واعر بزاف خويا`).
3. **Buttons** — verb + payment method. Always include الدفع عند الاستلام on the primary CTA.
4. **Numbers** — Western digits (`199`) — faster to scan in ads.
5. **No fake English luxury** on buttons. English is only the logo lockup.
6. **Never discount on the landing page.** 99 DH exists only behind the order submit.

## 5. Authority & trust stack (always visible above the fold on mobile)

1. **COD badge** — الدفع عند الاستلام
2. **Free shipping** — التوصيل مجاني لجميع المدن
3. **Speed** — 24–48 ساعة
4. **Social proof counter** — +12.400 طلب من المغرب
5. **Stars** — 4.9/5 with review count
6. **City-named reviews** — فاطمة · مراكش, يوسف · طنجة (never generic “User123”)
7. **Scarcity bar** — limited stock *today* (session-seeded remaining count, not a hard lie in the database)

Do not invent government certifications. Do not use fake “Visa Secure” marks (we do not take cards).

## 6. Pricing psychology (Morocco AOV)

| Tier | Price | Framing |
|---|---|---|
| 1 قطعة | 199 DH | Anchor. Still “premium USB”, not 79 DH junk. |
| 2 قطع | 279 DH | **Default**. Save 119 vs two singles. Gift + house. Badge: الأكثر طلباً |
| 3 قطع | 349 DH | Family pack. Badge: أفضل قيمة |

Math the customer feels:

- 2 × 199 = 398 → 279 (they “win” 119 DH without a coupon)
- 3 × 199 = 597 → 349

Cross-sell stays at **199** so the landing page price never looks discounted.  
Upsell at **99** feels like a private door-buster because they already committed.

## 7. Page-level CRO checklist

### Product landing

- [ ] Scarcity + free shipping in the first 80px
- [ ] Hero: product visual + Darija headline + 3 bullets + stars
- [ ] Tier selector large enough for thumbs
- [ ] Primary CTA sticky on mobile
- [ ] Alternating feature rows (text/image, then image/text)
- [ ] 6 city-tagged reviews
- [ ] FAQ that kills COD objections (“واش خاصني نخلص دابا؟ لا.”)

### Cart drawer

- [ ] Opens instantly on CTA (no page jump)
- [ ] Shows tier savings vs 199 × qty
- [ ] One-tap cross-sell of a **different** catalog USB
- [ ] Single CTA to checkout popup

### Checkout popup

- [ ] Exactly 3 fields: الاسم الكامل، رقم الهاتف، المدينة
- [ ] City is a searchable list of Moroccan cities (no free-text typos)
- [ ] Phone errors in Darija (“دخل رقم بحال 06 أو 07 أو 05”)
- [ ] Submit label: أكّد الطلب — الدفع عند الاستلام

### Upsell

- [ ] 10–15s countdown (we use **12s**)
- [ ] Product they did **not** just buy
- [ ] Decline is text, not a competing gold button

### Thank you

- [ ] Order id + recap
- [ ] “غادي نتصلو بك”
- [ ] 24–48h Morocco-wide
- [ ] No second upsell (protect trust)

## 8. Ad-to-page message match

If the ad says “القرآن كامل بـ 199 والدفع عند الاستلام”, the first screen of `/products/quran` must repeat **القرآن**, **199**, and **الدفع عند الاستلام** without a new story. Message mismatch is the #1 wasted-spend leak on Moroccan paid social.
